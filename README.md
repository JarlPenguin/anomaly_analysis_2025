# Поиск аномалий при анализе временных рядов финансовых и иных показателей коммерческих банков и юридических лиц методами машинного обучения

![Поддерживаемые версии Python](https://img.shields.io/badge/python-3.8%2B-blue)

Проект посвящён обнаружению аномалий, анализу и прогнозированию временных рядов финансовых показателей коммерческих банков (ВТБ и ФК «Открытие») методами статистики и машинного обучения.

**Курсовая работа студентов 2-го курса ОП «Экономика» НИУ ВШЭ.**

## Описание

В рамках работы исследуется динамика **просроченной задолженности по ипотечным жилищным кредитам** (форма отчетности ЦБ РФ 0409316). Временные ряды содержат структурные сдвиги (аномалии), вызванные слияниями и поглощениями в банковском секторе.

**Цель проекта: выявление аномалий временных рядов субъектов исследования, выбор наиболее подходящей модели для предсказания будущих значений и краткосрочный прогноз.**

**Поставленные задачи:**
1. Парсинг и консолидация данных отчётности разных банков по форме 0409316 (2016-2021 гг.).
2. Статистический анализ собранных данных.
3. Выявление и обработка аномалий (выбросов).
4. Сравнительный анализ моделей прогнозирования (статистические и модели машинного обучения).

## Структура данных

В качестве источника данных используются отчётности разных банков по форме 0409316 с сайта Центрального Банка РФ:
* **Период:** Январь 2016 - Декабрь 2021.
* **Показатели:** Суммарная просроченная задолженность по ипотечным кредитам.

Конвертация `.dbf` -> `.csv` реализована с помощью ПО Microsoft Excel.

В проекте реализован парсер, объединяющий данные до смены формы отчётности (2016-2018 гг.) и после (2019-2021 гг.).

## Методология и модели

### 1. Предобработка (EDA)
* Проверка на стационарность (тест Дики-Фуллера).
* Обнаружение аномалий.
* Дифференцирование рядов для приведения к стационарному виду.

### 2. Моделирование
Было протестировано три подхода к прогнозированию на горизонт 4 месяца:

1.  **Двойное экспоненциальное сглаживание**
    * Подходит для рядов с трендом, но без сезонности.
2.  **ARIMAX**
    * Используется для учета структурных сдвигов (аномалий) как экзогенных факторов.
3.  **Random Forest (с горизонтом 1 месяца)**
    * Преобразование временного ряда в задачу supervised learning (обучение с учителем) с использованием лагов.
    * Использование Walk-Forward валидации.

## Результаты

Сравнение точности моделей (метрика MAE) на тестовой выборке:

| Банк | Лучшая модель | Параметры | Комментарий |
| :--- | :--- | :--- | :--- |
| **ФК «Открытие»** | **ARIMAX** | `(20, 1, 5)` | Наилучшая точность, модель корректно улавливает нисходящий тренд. |
| **ВТБ** | **Exp. Smoothing** | `alpha=0.32, beta=0.78` | ARIMAX и RF оказались слишком чувствительными к волатильности или пессимистичными. |
